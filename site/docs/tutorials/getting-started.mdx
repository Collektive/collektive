**Collektive** is composed of three components:

- the **DSL** (`collektive-dsl`), defining the aggregate operators and the runtime that executes them;
- the **compiler plugin**, which instruments your Kotlin code with the *alignment* information needed to match
  the messages exchanged by devices with the operators that produced them (see [Alignment](../explanation/alignment.mdx));
- the **standard library** (`collektive-stdlib`), providing ready-to-use collective building blocks
  (distances, broadcasts, collection, gossip, leader election, …).

Collektive is a [Kotlin Multiplatform](https://kotlinlang.org/docs/multiplatform-intro.html) library built with **Gradle**:
the same aggregate program can be compiled for the JVM, JavaScript, and native targets,
but Collektive works just as well in a single-platform project (e.g., JVM only).

## Compiler plugin setup

First, apply the Collektive Gradle plugin in your `build.gradle.kts` file.
The plugin adds the compiler plugin to every Kotlin compilation of the project.

<Tabs>
<TabItem value="multiplatform" label="Multiplatform">

```kotlin
plugins {
    kotlin("multiplatform") version "<kotlin version>"
    id("it.unibo.collektive.collektive-plugin") version "<latest version>"
}
```

</TabItem>
<TabItem value="jvm" label="JVM only">

```kotlin
plugins {
    kotlin("jvm") version "<kotlin version>"
    id("it.unibo.collektive.collektive-plugin") version "<latest version>"
}
```

</TabItem>
</Tabs>

:::danger
The **compiler plugin** is a mandatory component of Collektive.
Without it, programs compile but fail at runtime with an `AlignmentClashException`,
as soon as they contain more than one aggregate operator.
:::

The plugin is enabled by default. If needed, it can be disabled for a specific project:

```kotlin
collektive {
    collektiveEnabled = false
}
```

## Dependencies setup

Then, add the `collektive-dsl` and (optionally, but recommended) the `collektive-stdlib` dependencies:

<Tabs>
<TabItem value="multiplatform" label="Multiplatform">

```kotlin
kotlin {
    jvm()
    js { browser(); nodejs() }
    // other targets...
    sourceSets {
        commonMain {
            dependencies {
                implementation("it.unibo.collektive:collektive-dsl:<latest version>")
                implementation("it.unibo.collektive:collektive-stdlib:<latest version>")
            }
        }
    }
}
```

</TabItem>
<TabItem value="jvm" label="JVM only">

```kotlin
dependencies {
    implementation("it.unibo.collektive:collektive-dsl:<latest version>")
    implementation("it.unibo.collektive:collektive-stdlib:<latest version>")
}
```

</TabItem>
</Tabs>

The latest version is shown on [Maven Central](https://central.sonatype.com/artifact/it.unibo.collektive/collektive-dsl).

:::tip[**Collektive** :heart: Kotlin Multiplatform]
Collektive supports the following targets:
- **JVM** (including Android applications);
- **JavaScript** (browser and Node.js);
- **Native**: macOS, iOS, tvOS, watchOS, Linux, Windows (MinGW), and Android Native.
:::

## What's next

Collektive is a language: to see it in action, programs must be executed by a set of devices that communicate.
The quickest ways to get started are:

- the [Alchemist simulator](collektive-and-alchemist.mdx), to run your programs on simulated networks of devices;
- one of our [template repositories](../references.mdx#template-repositories), with ready-to-use project setups.

Then, write your [first Collektive program](first-collektive-program.mdx),
and learn the concepts behind it in the [Explanation](/docs/category/explanation/) section.
