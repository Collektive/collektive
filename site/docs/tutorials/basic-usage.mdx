This tutorial builds a few small programs with the core aggregate operators,
from one-hop interactions to network-wide computations.
All results refer to a line of five devices with IDs `0 - 1 - 2 - 3 - 4`.
The operators used here are described in detail in [Aggregate Operators](../explanation/dsl-descriptions.mdx).

## Counting neighbors

```kotlin
import it.unibo.collektive.aggregate.api.Aggregate
import it.unibo.collektive.aggregate.api.neighborhood

fun Aggregate<Int>.neighborCounter(): Int = neighborhood().neighbors.size
```

[`neighborhood()`](https://javadoc.io/doc/it.unibo.collektive/collektive-dsl/latest/collektive-dsl/it.unibo.collektive.aggregate.api/neighborhood.html)
returns the [`Field`](../explanation/fields.mdx) of the neighbors aligned with the current device,
exchanging only the minimal information needed to discover them.
`neighbors` excludes the device itself, so its `size` is the number of neighbors.

Result: `{0=1, 1=2, 2=2, 3=2, 4=1}`.

## The maximum ID around me

```kotlin
import it.unibo.collektive.aggregate.api.neighboring
import it.unibo.collektive.aggregate.values
import it.unibo.collektive.stdlib.collapse.max

fun Aggregate<Int>.maxNeighborID(): Int = neighboring(localId).all.values.max()
```

[`neighboring`](https://javadoc.io/doc/it.unibo.collektive/collektive-dsl/latest/collektive-dsl/it.unibo.collektive.aggregate.api/neighboring.html)
sends a value (here, the device ID) to all neighbors, and returns the `Field` of the values received.
`all.values.max()` collapses the field into its maximum, *including* the local value.

Result: `{0=1, 1=2, 2=3, 3=4, 4=4}`.

## Going further: two hops

Information obtained through `neighboring` travels exactly one hop.
Composing two calls, the maximum spreads two hops away:

```kotlin
fun Aggregate<Int>.maxIDWithinTwoHops(): Int {
    val maxAroundMe = maxNeighborID()
    return neighboring(maxAroundMe).all.values.max()
}
```

Result: `{0=2, 1=3, 2=4, 3=4, 4=4}`.

## The maximum ID in the network

To reach any distance, the value computed at each round must be fed back and shared again.
This is what [`share`](https://javadoc.io/doc/it.unibo.collektive/collektive-dsl/latest/collektive-dsl/it.unibo.collektive.aggregate.api/share.html) does:

```kotlin
import it.unibo.collektive.aggregate.api.share

fun Aggregate<Int>.maxNetworkID(): Int = share(localId) { ids -> ids.all.values.max() }
```

At every round, each device shares the largest ID it knows, so the maximum advances by one hop per round.
After a few rounds: `{0=4, 1=4, 2=4, 3=4, 4=4}`.

:::caution
This program never forgets: if device `4` leaves the network, the others keep returning `4`.
The standard library's [`gossipMax`](../explanation/standard-library/gossip-and-leader-election.mdx#gossip)
solves the same problem in a *self-stabilizing* way, recovering from such changes.
:::

## The diameter of a subnetwork

Finally, let's compute, for a given source, how far the farthest device is (in hops),
and let every device know it.
We compose three standard library blocks:
a distance ([`hopDistanceTo`](../explanation/standard-library/spreading.mdx#distances)),
a collection towards the source ([`convergeCast`](../explanation/standard-library/collection.mdx)),
and a broadcast from the source ([`gradientCast`](../explanation/standard-library/spreading.mdx#broadcasts-gradient-casts)):

```kotlin
import it.unibo.collektive.stdlib.accumulation.convergeCast
import it.unibo.collektive.stdlib.ints.FieldedInts.toDouble
import it.unibo.collektive.stdlib.spreading.gradientCast
import it.unibo.collektive.stdlib.spreading.hopDistanceTo
import it.unibo.collektive.stdlib.util.hops

fun Aggregate<Int>.subnetDiameter(isSource: Boolean): Int {
    // G: how many hops away from the source am I?
    val distance = hopDistanceTo(isSource)
    // C: the source collects the largest distance
    val farthest = convergeCast(local = distance, sink = isSource) { a, b -> maxOf(a, b) }
    // G: the source shares it with everybody
    return gradientCast(source = isSource, local = farthest, metric = hops().toDouble())
}
```

With source `0`: `{0=4, 1=4, 2=4, 3=4, 4=4}`.
With several sources, each device computes the value for the subnetwork of its nearest source.
Using the device with the maximum ID as source (`subnetDiameter(localId == maxNetworkID())`)
combines this program with the previous one: this is the program executed in the [Alchemist tutorial](collektive-and-alchemist.mdx).
